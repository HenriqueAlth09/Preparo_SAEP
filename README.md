# Projeto SAEP - Sistema de Gestão para Empresa Alimentícia

Este repositório documenta o sistema desenvolvido como parte da minha preparação para a prova avaliativa do **SAEP**. O objetivo principal foi criar uma aplicação web funcional para ajudar na organização interna de uma empresa fictícia do ramo alimentício, cobrindo desde a modelagem dos dados até a interface do usuário e o gerenciamento completo de tarefas.

---

## O que foi desenvolvido?

Durante o projeto, passei por todas as etapas fundamentais de construção de um sistema com base nas entregas exigidas:

1. **Diagrama Entidade-Relacionamento (Modelo Lógico):** Criação do diagrama para representar o cenário proposto com base na regra de negócio[cite: 1].
2. **Criação do Banco de Dados:** Implementação física do banco de dados e exportação do script de criação/backup[cite: 1].
3. **Caso de Uso:** Elaboração do diagrama de caso de uso para ilustrar o cenário do sistema de gerenciamento de tarefas[cite: 1].
4. **Tela de Cadastro de Usuários:** Tela para cadastro de novos usuários com persistência dos dados na base (exigindo Nome e E-mail)[cite: 1].
5. **Tela de Cadastro de Tarefas:** Tela para cadastrar novas tarefas associando-as a um usuário, com persistência dos dados e classificação por setor e importância[cite: 2].
6. **Tela de Gerenciamento de Tarefas:** Painel de controle completo com funcionalidades para visualizar, editar, excluir e atualizar registros diretamente no banco de dados[cite: 2].
